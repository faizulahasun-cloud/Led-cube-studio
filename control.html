LED Cube Studio — Web Bluetooth Control

Connect to an HM-10 compatible BLE module (HM-10/CC2541 clones). This page implements a minimal control interface: Connect, Auto/Manual, Prev/Next animation, brightness, and send a demo frame.

Send a full 64-byte frame: the protocol is 'S' + 64 bytes + 1 checksum byte. The HM-10 will only accept ASCII/binary bytes via the characteristic.

Use the demo to send a random pattern or paste a hex/byte list into the box below (comma or space separated).
